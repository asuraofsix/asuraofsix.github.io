# Вредные привычки — Telegram Mini App (интерфейс, v0.1)

Один файл `index.html`, без сборки. Данные пока хранятся локально (localStorage).

## Запуск в Telegram
1. Выложите `index.html` на любой HTTPS-хостинг (GitHub Pages, Vercel, Netlify, Cloudflare Pages).
2. В @BotFather: `/newapp` (или `/setmenubutton`) и укажите URL страницы.
3. Откройте бота: приложение запустится внутри Telegram.

Вне Telegram (в браузере) файл тоже открывается, тема берётся из системы.

## Что внутри
- Сегодня: карточки привычек, счётные палочки, +/−, «Сегодня не было», лента последних 7 дней.
- Статистика: 7/30 дней, график с линией лимита, среднее, дни в лимите, серия.
- Привычки: каталог из 10 привычек, настройка дневного лимита.
- Telegram: тема и цвета, haptic feedback, BackButton в настройках, showConfirm, safe areas.
